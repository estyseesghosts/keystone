## 1. What we are building

Misskey-family Pages in Keystone v2, with three changes from Misskey's web UI:

1. **One editor screen.** Page settings at the top, content blocks below. No separate Settings/Contents tabs.
2. **Edit / Preview tabs.** Preview renders the unsaved draft with the exact component the reader uses.
3. **Formatting toolbar on text blocks.** Select text, tap a control, the text is wrapped. A settings toggle "Show formatting in editor" switches text blocks between raw source and rendered formatting. Preview always renders.

Plus the reader (`/@user/pages/name` equivalent), the Pages index (Featured / My pages / Liked), the profile Pages tab, and pin-to-profile.

### Formatting syntax is MFM, not Markdown

Misskey stores `text` blocks as a plain string and renders it with MFM (`page.text.vue`: `<Mfm :text :isNote="false">`). Anything else Keystone writes will render as literal characters on misskey.io and every other client. So the toolbar emits the **Markdown-compatible subset of MFM**:

| Control | Emitted | Notes |
|---|---|---|
| Bold | `**text**` | |
| Italic | `<i>text</i>` | Not `*text*`: mfm-js `italicAsta` only matches ASCII letters/digits/space, so `*日本語*` stays literal. |
| Strikethrough | `~~text~~` | |
| Inline code | `` `text` `` | Disabled when the selection contains a newline. |
| Code block | ```` ```\ntext\n``` ```` | Fences on their own lines. |
| Quote | `> ` per selected line | Toggles off when every selected line already has the prefix. |
| Link | `[text](url)` | Prompts for URL; http(s) only (reuse `safeUrl`). |
| Center | `<center>text</center>` | On its own lines. |
| Small | `<small>text</small>` | |

Headings and lists do **not** exist in MFM. Headings = Section blocks. Lists are plain text. Neither gets a control.

Rule for agents: the toolbar may only emit syntax that `fromMfm` maps to a rendered node. `center` and `small` map to `fn` nodes today (`fromMfm.ts:148,197`); confirm `RichText` renders them (`fnStyle.ts`) before shipping those two controls, else drop them and log it.

## 2. Server contract (do not re-derive; cite this)

Full detail: `docs/pages-clips.md` §4, `docs/pinetree-pages-clips.md` §4.1. Summary:

| Endpoint | Auth / kind | Params | Returns | Errors to map |
|---|---|---|---|---|
| `pages/show` | optional | `{pageId}` or `{name, username}` (local users only) | packed Page | `NO_SUCH_PAGE` (222120c0) |
| `pages/create` | `write:pages`, 10/h | `title*, name*, content*, variables*, script*, summary?, eyeCatchingImageId?, font?, alignCenter?, hideTitleWhenPinned?` | packed Page | `NAME_ALREADY_EXISTS` (4650348e), `NO_SUCH_FILE` (b7b97489), 429 |
| `pages/update` | `write:pages`, 300/h, owner only | `pageId*` + any create field (undefined = untouched, `null` clears `summary`/`eyeCatchingImageId`) | 204/void | `NAME_ALREADY_EXISTS` (2298a392), `NO_SUCH_PAGE`, `ACCESS_DENIED`, `NO_SUCH_FILE` |
| `pages/delete` | `write:pages`, owner or moderator | `pageId*` | 204 | `NO_SUCH_PAGE`, `ACCESS_DENIED` |
| `pages/like` / `pages/unlike` | `write:page-likes` | `pageId*` | 204 | `YOUR_PAGE`, `ALREADY_LIKED`, `NOT_LIKED`, `NO_SUCH_PAGE` |
| `pages/featured` | optional | `{}` | Page[] ≤10 | — |
| `users/pages` | optional | `userId*`, `limit`, `sinceId`, `untilId` | Page[] | — |
| `i/pages` | `read:pages` | paging | Page[] (no `isLiked`) | 404 on Pinetree |
| `i/page-likes` | `read:page-likes` | paging | `{id, page}[]` | 404 on Pinetree |
| `i/update` | `write:account` | `pinnedPageId: id \| null` | Account | `NO_SUCH_PAGE` |

Packed Page: `id, createdAt, updatedAt, userId, user (UserLite), content (PageBlock[]), variables, title, name, summary|null, hideTitleWhenPinned, alignCenter, font ('serif'|'sans-serif'), script, eyeCatchingImageId|null, eyeCatchingImage (DriveFile|null), attachedFiles (DriveFile[]), likedCount, isLiked?`.

Blocks (all have `id: string, type: string`):

- `text`: `text: string`
- `section`: `title: string, children: PageBlock[]` (recursive, unbounded)
- `image`: `fileId: string | null` — the reader resolves it against `page.attachedFiles`; the server derives `attachedFiles` from image blocks owned by the author.
- `note`: `note: string | null, detailed: boolean`
- Legacy AiScript types (`button`, `if`, `textarea`, `post`, `canvas`, `numberInput`, `textInput`, `switch`, `radioButton`, `counter`, `input`) still exist in old rows. Misskey renders them as a "dynamic block, abolished" placeholder.

`name` regex (`pageNameSchema`): `/^[^\s:\/?#\[\]@!$&'()*+,;=\\%\x00-\x20]{1,256}$/`. Unique per user. `title`, `summary` ≤256 (DB limit; overflow is a 500, so validate client-side).

Canonical public URL: `{origin}/@{username}/pages/{name}`.

Pinetree differences that matter here: `i/pages` and `i/page-likes` 404; `pinnedPage` is always `null` (fetch by `pinnedPageId`); `update`/`unlike` return 204; non-owner update → `NO_SUCH_PAGE`; `drive` capability is `unsupported`. Pinetree-only fields (`pageVisibility`, `visibleUserIds`, `federate`, `approvedActorUris`) are out of scope (§7).

Contract rules already in AGENTS §6 apply: Sharkey 400s unknown fields, 204 handling, per-origin tokens.

## 3. Decisions made in this plan

| ID | Decision | Reason |
|---|---|---|
| PG-1 | Text formatting = MFM subset (§1 table). | Only format Misskey renders. |
| PG-2 | "Show formatting in editor" is a **device-local editor preference** (MMKV, device scope), not a page field. Default `false`. | No server field exists; sending one 400s on Sharkey. |
| PG-3 | Unknown/legacy blocks are preserved verbatim on load and save, shown read-only in the editor, placeholder in reader/preview. | Editing an old page must never destroy content. |
| PG-4 | `pages/update` sends **only changed fields**. Never sends `script` or `variables` on update. `pages/create` sends `script: ''`, `variables: []` (required). | Misskey web hard-codes `script: ''` on every save and wipes legacy scripts. We do not. |
| PG-5 | AiScript is never executed. No `page-push`, no `pageEvent`. | Removed upstream; Pinetree has none; security. |
| PG-6 | Block reorder = Move up / Move down / Move into section above / Move out of section (menu + buttons). No drag-and-drop. | No DraggableList in the repo; buttons work on all targets and with keyboard/screen readers. |
| PG-7 | Reader and Preview share one component (`PageView`). Only the image resolver and the action bar differ. | Preview must match the published page. |
| PG-8 | Editor keeps a local draft (MMKV, account scope) keyed by `pageId` or `new`. Restore prompt on reopen. Cleared on successful save. | Pages are long; losing them to a crash or nav is costly. Pattern: `src/storage/drafts.ts`. |
| PG-9 | In-editor rendering approach is decided by Slice 0 spike (ADR 0014). Fallback is render-on-blur (§5 Slice 6, option B). | Live styled text input on RN-web + native is unproven in this repo. |
| PG-10 | Signed-out viewers see no like control. Owners see no like control. | Misskey shows a button that fails with 401 / `YOUR_PAGE`. AGENTS §6: no inert controls. |
| PG-11 | Routes: `Pages: /pages`, `Page: /pages/view/:id`, `PageEdit: /pages/edit/:id?` (no id = new). | Unambiguous with React Navigation path matching; mirrors Misskey's `/pages/edit/:id`. |

Record PG-1..PG-11 in `docs/DECISIONS.md` (one line each) in Slice 1. PG-9 becomes ADR 0014 in Slice 0.

## 4. Architecture

### `packages/fedi` (pure TS)

- `core/models.ts`: add domain types
  ```ts
  type PageFont = 'serif' | 'sans-serif'
  type PageBlock =
    | {kind: 'text'; id: string; text: string}
    | {kind: 'section'; id: string; title: string; children: PageBlock[]}
    | {kind: 'image'; id: string; fileId: string | null}
    | {kind: 'note'; id: string; noteId: string | null; detailed: boolean}
    | {kind: 'unknown'; id: string; type: string; raw: Record<string, unknown>}
  interface PageModel {
    id, createdAt, updatedAt, author: Account, title, name, summary: string | null,
    font: PageFont, alignCenter, hideTitleWhenPinned,
    eyeCatchingImageId: string | null, eyeCatchingImage: Media | null,
    attachedFiles: Media[], blocks: PageBlock[], likedCount: number,
    isLiked: boolean | undefined, hasLegacyScript: boolean, url: string
  }
  ```
  Known blocks keep any extra wire fields in a private `extra` record so they round-trip (PG-3).
- `core/backend.ts`: `PagesApi` (optional module, like `ClipsApi`):
  `show({id} | {username, name})`, `create(draft)`, `update(id, patch)`, `delete(id)`, `like(id)`, `unlike(id)`, `featured()`, `byUser(userId, PageOpts)`, `mine?(PageOpts)`, `liked?(PageOpts)`, `pin(id | null)`.
  `mine`/`liked` are absent when `pages_own_lists` is not supported.
- `core/detect.ts`: feature keys `pages` and `pages_own_lists`.
  misskey, sharkey: both `supported`. pinetree: `pages: supported`, `pages_own_lists: unsupported`. catodon: leave unset (unknown → hidden), same as `clips`. mastodon/akkoma/pleroma: both `unsupported`.
- `core/pageName.ts`: `isValidPageName`, `defaultPageName()` (`Date.now().toString()`), `copyName(name, n)`.
- `core/content/mfmFormat.ts`: pure text edits. `applyFormat(text, selection, control, arg?) → {text, selection}` and `activeFormats(text, selection) → Control[]`. Toggles off when the selection is already wrapped (markers inside or immediately outside the selection).
- `misskey/pages.ts`: wire ↔ domain adapt + serialize, the endpoint calls, error-code mapping into `core/errors.ts` codes.
- `misskey/auth.ts`: add `read:pages`, `write:pages`, `read:page-likes`, `write:page-likes` (Misskey exact-matches `kind`). Old tokens hit the existing scope-upgrade path (`ScopeUpgradeBanner`).
- Fixtures `test/fixtures/misskey/pages-*.json`: hand-built from the upstream schema, marked `"_synthetic": true` in `manifest.json`. Owner replaces with `scripts/fedi-capture.ts` output (live-checks).

### Slice 5 — Formatting toolbar

- **Goal:** select text, tap a control, text is formatted.
- **Files:** `src/components/PageEditor/{FormatToolbar,TextBlockEditor}.tsx` (+tests), locale.

  6. Web shortcuts while the text block is focused: Ctrl/Cmd+B bold, +I italic, +K link, +Shift+X strike. Follow `src/components/web-keyboard` patterns.
- **Acceptance:** component tests per control (selection in → text + selection out); toolbar hidden when no text block focused; shortcut tests on web; manual: Android + web select-and-format recorded (screenshot/GIF) or `not verified`.
