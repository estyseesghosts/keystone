# Keystone wiki

Simple-language guides for non-technical readers. Short sentences. No assumed knowledge.

## Pages

- [What is Keystone?](what-is-keystone.md) — what the app does, in plain terms. Start here.
- [Installing and running](installing-and-running.md) — how to install and launch the app. For anyone setting it up on a computer.
- [Using the app](using-the-app.md) — accounts, timelines, posting, notifications, settings. For anyone using the app day to day.
- [Accounts and servers](accounts-and-servers.md) — Misskey vs Mastodon, and how sign-in works. For anyone confused about servers.
- [Troubleshooting and FAQ](troubleshooting-and-faq.md) — common problems and where to look. For anyone stuck.
- [Glossary](glossary.md) — one-sentence definitions of words this project uses in special ways. For anyone lost in jargon.

## A note on status

Keystone v2 is unfinished. The code repair program finished on 2026-10-25, but checks on real phones and live servers are still pending with the owner. Screens may look rough. Some buttons may be greyed out with a reason. That is on purpose: a greyed-out button with a reason is better than a button that pretends to work.

If a wiki page says "verify in app", it means the writer described what the code says, but nobody has confirmed it by tapping through the real app yet.
