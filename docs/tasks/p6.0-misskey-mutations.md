## Steps

- [x] 1. `UploadOptions` gains optional `folderId`/`force`; the multipart
  `drive/files/create` body carries them only when the caller sets them
  (null/empty folder = root = omitted). `Backend.uploadMedia` opts typed
  as `UploadMediaOpts`; misskey backend builds the multipart opts
  explicitly; `uploadOne`/`uploadAll`/`useUploads` take an `UploadTarget`;
  `Composer` exposes `uploadFolderId` and passes it (`null` = root).
- [x] 2. `EditNoteParams` mirrors create for `noQuote` and the poll shape;
  `editPost` sends both on `notes/edit`. A 4xx (e.g. poll edit rejected)
  propagates as the typed `ApiError` — never swallowed.
- [x] 3. Removed the `seedLikeSupport(origin, false)` block from
  `misskey/backend.ts` and the seed helper itself: stock Misskey probes
  `notes/like` once on the first press, caches a real 404, and only then
  falls back to a plain ❤ reaction. Success caches `true`.
- [x] 4. `listScheduledNotes`/`listServerDrafts` accept `sinceId`;
  backend `scheduled.list`/`serverDrafts.list` pass
  `cursor.untilId` + `cursor.sinceId` (the `adapt.ts` cursor already
  encodes both).
