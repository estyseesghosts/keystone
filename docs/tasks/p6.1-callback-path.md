# P6.1 — OAuth callback under a base path (v1 `/keystone/callback` accepted)

Plan ref: `docs/clickstone.md` §1.13 (Wave 1)
Status: done
Branch: `p6.1-callback-path`

## Goal

Accept both OAuth/MiAuth callback URLs — v1's root-base `/keystone/callback`
and v2's canonical `/auth/callback` — in the app, at a root and under a
deployed base, without changing the redirect URI already registered with
instances.

- [x] 5. Tests: both paths resolve (root + under base, query preserved),

## Out of scope

- Changing the registered redirect URI to the v1 base-relative form
  (`${origin}${base}/auth/callback`) — deliberately not done, see the
  session log.
- Rewriting the address bar from the legacy path to canonical (both stay
  valid; the screen leaves via `Main`).
- `packages/fedi` `DEFAULT_CALLBACK_PATH` (still `/keystone/callback`; the
  app passes its own path, and both are routed).
- `scripts/fedi-smoke.ts`, native deep-link scheme/prefixes (unchanged).
