      `accountPosts(id, {withReplies: true, withRenotes: true})`; Posts /
      Replies / Media keep their existing flags.
- [x] 3. Insert `All` into `ProfileTabs` order after Posts (Featured
      stays first/conditional; Replies and Media stay).

      replies + boosts); Misskey sends `withReplies` + `withRenotes` true.
      Pinned by backend tests.
- [x] 6. Tests: ProfileTabs order (5 tabs with Featured, 4 without),
      onChange for `all`; descriptor parse/format/guard; dispatch opts;
      Mastodon + Misskey wire params.
