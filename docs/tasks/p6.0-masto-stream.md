# P6.0 — Mastodon streaming safety

Plan ref: `docs/clickstone.md` §"Wave 0 — correctness", slice 0.1
Status: done
Branch: `p6.0-masto-stream`

## Goal

Make the Mastodon-family WebSocket client safe: token via
`Sec-WebSocket-Protocol`, ping/pong, `kill` + `filters_changed`, a bounded
reconnect breaker with an honest dead state, and a scheme-pinned streaming
origin.

## Steps

- [x] 1. Auth as subprotocol pair (`["Bearer", token]`); `streamUrl` keeps the
      URL token-free; factory seam takes `(url, protocols?)`.
- [x] 2. Reply `pong` to the bare text `ping` frame (and a defensive
      `{event:"ping"}` shape) without routing it as an event.
- [x] 3. `kill` closes that socket and never redials (entry marked dead /
      `stopped`); `filters_changed` exposed via
      `handle.onFiltersChanged`, wired in `useFeedLive` to invalidate
      `serverFiltersQueryKey(sessionId)`.
- [x] 4. 10s open/`connected` ack watchdog; breaker after 5 fast closes
      (<10s lifetime, or a dial that never opened) → `stopped`; `retry()`
      clears the breaker and re-dials; `StreamBadge` shows “Live updates
      stopped” with Retry (no infinite “Reconnecting…”).
- [x] 5. Scheme pin: an advertised streaming origin only survives when its
      scheme matches the session origin (`https`→`wss`, `http`→`ws`);
      otherwise the session origin's ws(s) mapping is used. Applied both at
      discovery (`normalizeStreamingOrigin(raw, sessionOrigin)`) and at dial
      time (`resolveStreamingBase`).
- [x] 6. `subscribePost` still rides the shared `user` socket (no per-post
      socket added).

## Acceptance

- [x] `pnpm typecheck && pnpm lint && pnpm test` green
- [x] header-not-query: URL has no `access_token`/token; factory receives
      `["Bearer", token]`
- [x] ping frame → `pong`, routing undisturbed
- [x] `kill` closes without retry (fake timers; no new socket)
- [x] breaker trips after 5 fast closes → `stopped`; manual retry re-dials and
      clears it
- [x] 10s ack timeout covered (fake timers)
- [x] cross-scheme advertised origin refused; session-origin fallback used;
      token never dialed to the refused host
- [x] `filters_changed` invokes the registered handler
- [x] feeds keep polling when the stream is dead (no behavior removed)
