# P6.1 — Soft-mute badge

Plan ref: `docs/clickstone.md` §1.3 (Wave 1)
Status: done
Branch: `p6.1-soft-mute-badge`

## Goal

Notes whose (rendered) author is soft-muted but which are still on
screen — threads, profiles, notifications, any surface that does not
drop them — carry an honest "Soft-muted" badge; feeds keep dropping
them exactly as before.

## Read first

- `AGENTS.md` §5–6 (pure `packages/fedi`, UI-only badges, no fake data,
  absent signal means no badge)
- `docs/clickstone.md` §1.3
- `docs/2026-10-22-full-audit-mastodon-misskey-v1-parity/full-audit.md`
  §1.2 A4
- `src/components/Post/badges.ts` + `.test.ts`,
  `src/components/Post/PostCard.tsx` (`LivePostCard` / `PostCardView`),
  `src/state/queries/graph.ts` (`useSoftMutedIds`, `filterSoftMuted`,
  `softMuteStore`), `src/screens/HomeFeed.tsx` (feed filter)

## Steps

- [x] 1. `isSoftMutedPost(post, mutedIds)` in `src/state/queries/graph.ts`,
      the one predicate `filterSoftMuted` also uses (author, or pure
      renote whose original author is muted). No duplicate rule.
- [x] 2. `badgesFor(post, {softMuted?})`: pure, no store reads, badge
      `softMuted` labelled `Soft-muted`, right after `filtered` and
      before `reactions`. Omitted/false → no badge.
- [x] 3. `LivePostCard` reads `useSoftMutedIds(sessionId)` and passes
      `isSoftMutedPost(appearNoteOf(post), ids)` (the rendered author,
      so a pure boost is judged by its original). `PostCardView` takes
      the optional `PostCardProps.softMuted` for presentational trees.
- [x] 4. Feed filtering unchanged (§1.3: the badge is for what remains
      visible).
- [x] 5. Tests: `badges.test.ts` (4), `graph.test.tsx` predicate (5),
      `post.test.tsx` presentational render (3), `postactions.test.tsx`
      live card incl. renote + not-in-list (4).

## Acceptance

- [x] `pnpm typecheck && pnpm lint && pnpm test` green
- [x] `badgesFor` has no store/React dependency; badge absent without
      the explicit flag
- [x] Badge order pinned: `filtered` → `softMuted` → `reactions`
- [x] A pure renote of a soft-muted author is badged (live card); a
      renote of an unmuted author is not
- [x] `filterSoftMuted` behavior unchanged (existing tests still pass)
- [ ] device/web visual run — not verified (jest-only slice; a real
      soft-mute needs a live account)

## Out of scope

- Changing what feeds filter (hard words, server filters, soft mute).
- A "why is this hidden / show anyway" affordance for dropped rows.
- Locale catalog extraction (`Soft-muted` is new; coordinator compiles
  after merge).
