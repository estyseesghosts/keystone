# P6.1 — Channels UI (Misskey)

Plan ref: `docs/clickstone.md` §1.9 (Wave 1)
Status: done
Branch: `p6.1-channels`

## Goal

Ship the highest-value missing Misskey surface: `ChannelsApi` for the real
Misskey endpoints, the `channel|<id>` feed dispatch (data + live stream),
a `/channels` directory screen and a `/channels/:id` detail screen with
follow/unfollow — honestly gated so the Mastodon family shows an
unavailable state instead of an empty feed.

## Steps

- [x] 1. Core model: `Channel` gains `bannerUrl`/`isFollowing` (null =
      unreported)/`isArchived`/`usersCount`/`notesCount`; `ChannelsApi`
      gains `show`/`followed`/`follow`/`unfollow` plus a `list` query
      option. `FeedSource` gains `{channelId}`.
- [x] 2. `packages/fedi/src/misskey/channels.ts`: `channels/search`
      (directory, paged), `channels/show`, `channels/timeline`,
      `channels/followed`, `channels/follow|unfollow`, compact adapter.
- [x] 3. `MisskeyBackend.channels` wired; capability `channels:
      supported` for misskey + sharkey (Mastodon `unsupported`, forks
      stay `unknown`); `read:channels`/`write:channels` added to
      `KEYSTONE_PERMISSIONS`.
- [x] 4. Feed dispatch: `channel|<id>` → `backend.channels.notes`
      (both-direction cursor paging); honest `errors.unsupported.channels`
      when the module is absent.
- [x] 5. Live stream: Misskey `channelSpec` maps `{channelId}` to the
      server's `channel` stream channel (`params.channelId`, public);
      `feedSourceKey`/`feedSourceForDescriptor` map `channel|<id>`; the
      Mastodon handle answers it as a disabled subscription.
- [x] 6. UI: `/channels` directory (rows, paging, refresh, honest
      signed-out/empty/error/unsupported) and `/channels/:id` (name,
      description, banner, archived note, follow/unfollow, descriptor
      feed). Routes + linking + sidebar entry + a `ChannelIcon`.
- [x] 7. Tests: backend call shapes, capability matrix, descriptor
      dispatch, stream subscribe/ack/dispatch/disconnect/close, route
      leaves + URLs, sidebar gate, directory + detail states, follow
      toggle + unknown-state reason.
