Luigi’s Picture Poker is a simplified, Mario-themed version of five-card draw. You receive five picture cards, choose which to keep, optionally increase your wager, draw replacements, and compare your hand against Luigi’s. Better combinations pay larger coin rewards.&#x20;

### Hand strength and payout

From weakest to strongest:

| Hand            | Requirement             | Multiplier        |
| --------------- | ----------------------- | ----------------- |
| Junk            | No matching pictures    | No winning payout |
| One pair        | Two matching            | ×2                |
| Two pairs       | Two separate pairs      | ×3                |
| Three of a kind | Three matching          | ×4                |
| Full house      | Three matching + a pair | ×6                |
| Four of a kind  | Four matching           | ×8                |
| Five of a kind  | All five matching       | ×16               |

These are the single-player payout multipliers in both games. Super Mario 64 DS labels the top hand “Flush”; New Super Mario Bros. DS calls it “5 of a kind.” It is not a conventional poker flush because the deck has no suits.&#x20;

### Hand evaluation

Count how many times each rank appears in the five cards. Sort those counts to identify the combination:

- `[5]` → five of a kind
- `[4,1]` → four of a kind
- `[3,2]` → full house
- `[3,1,1]` → three of a kind
- `[2,2,1]` → two pairs
- `[2,1,1,1]` → pair
- `[1,1,1,1,1]` → junk

Return a hand result containing both its category and a tie-break key. For a pair, for example, the key should place the pair's rank first, followed by the remaining card ranks in descending order. Compare category first, then the tie-break key. Treat junk versus junk as a draw in the initial clone.

### Round-resolution pseudocode

```
deal_round()
bet = choose_valid_bet()
player_discards = marked_cards()

draw_replacements(player_hand, player_discards)
luigi_discards = choose_luigi_discards(luigi_hand)
draw_replacements(luigi_hand, luigi_discards)

player_result = evaluate(player_hand)
luigi_result = evaluate(luigi_hand)

comparison = compare(player_result, luigi_result)

if comparison == WIN:
    coins += bet * multiplier(player_result)
    stars += 1
else if comparison == LOSS:
    stars = max(0, stars - 1)
else:
    refund_bet()

if coins <= 0:
    show_game_over()
else:
    show_result_and_offer_next_round()
```

This assumes the wager is deducted when committed, the winner receives `bet × multiplier`, and a draw refunds the wager. Keep all coin changes in one function so the UI cannot accidentally apply a payout twice.

### Luigi's AI

For a straightforward approximation:

1. Keep any existing pair or stronger combination.
2. Discard unpaired cards to seek improvements.
3. When the hand is junk, keep the highest-ranked card and discard the other four.
4. Draw random replacements from the remaining deck.

This provides a playable opponent. The references confirm that Luigi can replace cards, but do not fully document his discard algorithm, so this is a deliberate clone-design choice rather than a claim about the original AI.

## 5. Version differences and scope

The shared single-player loop is effectively the same in both DS games. The obvious differences include the “Hit” versus “Draw” button label and the name of the five-matching-cards hand. NSMB also has a multiplayer mode; there, players do not wager beforehand and the winning hand takes coins from the other players based on its category.&#x20;
