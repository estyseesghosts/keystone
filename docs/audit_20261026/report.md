# Keystone v2 audit — synthesis (2026-10-26)

Twelve agents audited the repo in parallel. Each wrote a report in `results/`. This document merges them, removes duplicates and ranks the findings.

**Method and limits.** Every audit was static code reading. No agent ran the app on a device, a simulator or a live server. The exceptions: the build agent ran the gates (typecheck ios/android/web, lint, tests — outputs pasted in its report), and the richtext agent re-measured parser nesting/depth behavior with a throwaway jest test (deleted afterwards, 287 ms total, no throws). Findings marked "needs device check" are inferred. Misskey/Mastodon upstream wire shapes recalled from memory are flagged as such in the misskey/mastodon reports (no server source is in the repo; fixtures remain synthesised). `pnpm audit` was not run.

**Gates.** `pnpm typecheck` (ios, android, web), `pnpm lint` and `pnpm test` all pass: **292 suites / 4123 tests** (195 src + 88 packages/fedi + 8 lint-rules + 1 plugins), 0 snapshots, 0 skips — matching `state/STATE.md` (28 lines) exactly. `--forceExit` is still required; the worker-exit warning persists (`test:handles` still never clean). One intentional `ts-expect-error`, zero `ts-ignore`, zero non-test `as any`.

## Overall assessment

The 2026-10-25 repair program held. Every audit reports the same shape: the large majority of prior findings verify as fixed in code — secret-free native envelope + SecureStore vault + per-session purge, `redirect: 'manual'` on all credentialed transports, CSPRNG-only randomness, default-deny persist policy, streaming breakers/pooling, Lightbox index/windowing, react-hooks lint, toast/dialog/heading/chip/focus-ring fixes, centralized locale formatting, and the Mastodon/Misskey wire-shape batch (`resolve=true`, list wrappers, search cursors, edit bodies, revoke params, poll honesty).

What remains is narrow, not structural:

1. **One unhardened legacy path.** `externalUploadFile` (`packages/fedi/src/misskey/external.ts:328-343`) missed every transport repair — the only credentialed fetch without `redirect: 'manual'` or a deadline. Reported independently by two agents.
2. **Two half-landed features.** Streaming-origin plumbing has a consumer but no producer (`detectServer` never writes the evidence); reconnect gap-fill covers only notification mounts and one transition shape.
3. **One dead retry-safety seam.** The stable idempotency helpers exist but have zero production callers (triple-reported); timeout-then-retry still double-posts.
4. **Purge/memory and settings-write gaps.** In-memory pref caches survive the on-disk purge and re-persist it (storage S1); one settings write path bypasses the token overlay and goes out unauthenticated on native (sessions-cache 1).
5. **Composer edit-mode honesty.** Poll/reaction controls are usable in edit mode but never reach the server; the close guard misses alt-only edits; create-mode submit has no attachment busy gate.
6. **Media residuals are low/medium, no highs.** Mastodon aspect nesting, Misskey/audio caps without server basis, unvetted avatar call sites, quote-grid `active`, viewer audio gate.
7. **Release hygiene is unchanged.** Debug-keystore signing, custom-scheme MiAuth (accepted risk, ADR 0012), web localStorage tokens (documented blocker), dev-only cleartext hatch — all need owner/device action, none is new.

## Suggested order of work

1. **Transport credential leak (one slice).** Mirror the internal upload in `externalUploadFile`: `redirect: 'manual'` + typed 3xx refusal, scaled/`DIRECT_TIMEOUT_MS` deadline, body read inside the guarded region. Add a regression test asserting no-follow + timeout parity across the four upload paths.
2. **Settings write + purge memory (one slice).** Resolve the recommendations settings backend through the session store (or inject `Backend`); add `clearSession` to recents/favourites/like-emoji/soft-mute caches, call from `purgeSessionMemory`, extend the enumeration test to read back through the real stores.
3. **Composer edit honesty (one slice).** Gate poll toggle + reactions row on `!editing` (or wire through where supported); emit `noQuote: false` on edit; include seeded/staged alt + `reactionAcceptance`/`noQuote` in the edit dirty diff; extend the create-mode busy gate to add/remove/alt/poll/visibility during submit; branch `CompactComposer` close dialog on `editing`.
4. **Retry safety (one slice).** Thread `attemptKeyForBody` through `createPost` + `scheduled.create` (composer-owned key, session-prefixed fingerprint); decide the Misskey no-mechanism note; cover timeout-then-retry with a test.
5. **Streaming completeness (one slice).** Merge `streamingEvidenceFor` into `detectServer` (+ `DetectionEvidence` fields, backfill on login/verify); wire gap-fill into `useFeedLive` and trigger on any away→connected transition; confirm the Mastodon subprotocol pair live (bare-token fallback if the recollection holds).
6. **Mastodon/Misskey tails (one batch).** Skip-and-count on the five remaining whole-page-fail paths; `notes/like` omit-null-`override` (verify live); `meta.original` aspect + Misskey/audio cap basis + avatar vetting; quote-cache bound + hit TTL + token-free key; dropped `signal`s; revocation identity; marker length rule; recommendation `end`; empty-ballot validation; chat `deleted` object shape; one live fixture per recalled shape.
7. **Chat + visibility + a11y/i18n (one batch).** Chat KAV + input label; visibility seed from cached `me` (or loading state on fresh composers); poll-expiry/foot `i18n` threading; `DisplayNames` locale; debug numerals via `formatNumber`; `faint` essential-text sweep; sheet/inline pointer + ghost-draft scoping; per-screen `Stack` boundaries.
8. **Release/device checks (owner).** Real Android signing key; App Links + domain + `assetlinks.json`; `app.config.js` D3 identifiers; web token story; 25 device checks + 12 rig live-checks (Misskey `:3101`, Sharkey `:3102`, Mastodon) including PKCE `btoa`/`redirect: manual`, Lightbox gestures, viewer audio, prebuild manifest/`Info.plist` stripping, backup exclusion, `keystone://` claimants.
9. **Hygiene tail.** `--detectOpenHandles` pass; `expo-asset`/`expo-constants` peer check (+ declare `expo-file-system` if the probe path stays); `.bak` scrub on vault migration; OAuth pending sweep; envelope-guard routing; manifest-orphan enumeration; `sessionIdFromKey`/`mutationKey`/`usePostFeedQuery` cleanups; audit-output tracking decision.
