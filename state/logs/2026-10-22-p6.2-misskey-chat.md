## Decided

- Separate `ChatApi`, not `ConversationsApi` reuse (shapes genuinely differ — see task file; recorded here per AGENTS.md §4).
- `direct_messages` flipped for misskey despite misskey.io 2025.4.1-io 404ing all `chat/*`: upstream `develop` HAS the full surface and old releases degrade per screen via the existing 404→unsupported path (same as every other version-skewed endpoint). Recorded in the task file.
- Timeline fetch IS the read mark (upstream marks server-side on every timeline call) — no per-thread mark call; `chat/read-all` is the inbox-level sweep exposed behind a two-step confirm.
- `connection.send('read')` over the socket NOT implemented (official-client extra; fetch already marks; no state Keystone tracks).
- Out of scope kept out: members/invitations inbox/join/leave, room update/delete/mute, message search, message reactions UI, file attachments in composer (wire `fileId` supported).
