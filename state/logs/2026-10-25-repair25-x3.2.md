## Decided

- D10: `@react-native-community/netinfo@12.0.1` (exact pin from SDK 57
  `bundledNativeModules.json`, which also lists `expo-network@~57.0.3`).
  NetInfo chosen because `onlineManager.setEventListener` needs a
  connectivity-listener subscription (the documented react-query/NetInfo
  pattern, confirmed against the installed `onlineManager.d.ts` example);
  expo-network is a one-shot query API with no listener to wire.
- Foreground budget starts on first sighting (mounts fetch on their own —
  no boot double-fetch); offline passes skip without consuming budget.
- Background suspend disposes app-layer subscriptions (socket close follows
  for pooled handles); the pending pill buffer is dropped and the gap-fill
  covers the miss. Reported DECISIONS line (not edited):
  `| 2026-10-25 | X3.2: online source is @react-native-community/netinfo@12.0.1 (exact SDK 57 bundledNativeModules.json pin); focus via AppState native / visibilitychange web; foreground refetch feed/notifications/me only with 60 s per-query gap (no global flip); streams suspend 30 s after background, resume nudges dead handles only, gap-fill first pages only, per-post update debounce 250 ms | networking-M3/M7 |`
- No ADR (no storage shape / model / key-shape / dependency-policy reversal;
  the one dep follows the D10 default).
