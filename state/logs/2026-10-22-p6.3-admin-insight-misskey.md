## Decided

- Permission strategy: three least-privilege grants (the exact `kind` strings), no umbrella
  (none exists — exact-match verified). Old tokens get the existing 0.8 upgrade prompt; the
  `admin/meta` (admin-only) vs `server-info`/`queue/stats` (moderator) role split is why
  sections degrade independently — a moderator sees everything except Instance settings.
- `adminInsight` member present-but-partial per family (each family implements only its own
  four/five methods; the other side throws typed-404). The alternative (making the five
  Mastodon methods optional) would reshape the merged Mastodon contract — rejected per brief.
- `misskeyAdminRoleOf` lives in `misskey/admin.ts` (distinct name — no barrel clash with the
  Mastodon `adminRoleOf`), exported through the barrel like the masto slice's D4.
- Online count renders for staff only (same as the Mastodon public fallbacks) — the screen
  itself is staff-gated; no new audience logic in this slice.
- React Compiler hazard (see below): optional-method closures are captured through an
  always-defined record, never as bare `admin.x` reads.

## Load-bearing discovery — React Compiler vs nullable bases

`babel-plugin-react-compiler` memoized the `run` closures as
`if ($[16] !== admin.serverInfo) { t7 = () => admin.serverInfo(); ... }` — an UNGUARDED eager
read of the nullable `admin` base during render, throwing `TypeError: Cannot read properties
of null (reading 'serverInfo')` whenever the module is absent (signed-out, pinetree, any
module-less backend). The compiler does NOT inherit the `?.` guard from the sibling `enabled`
flag. The five merged Mastodon closures escaped only because the compiler chose `admin`
itself as their dep. Rule for future slices: never let a closure body read `nullableBase.x`
bare — capture optionals into an always-defined record first (here `misskeyInsight`), so the
synthesized dep reads are safe by construction. Verified in the compiled output (no remaining
`!==admin.<method>` reads). Two pre-existing tests caught it (`signed out`, `no insight
module`) — the gates that exercise the null base.
