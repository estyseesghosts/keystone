## Decisions

- Mutations return `void` on both families (Mastodon discards the answered row; Misskey has no re-read endpoint): UI confirms, then refetches. No optimistic updates.
- Mastodon `resolve(id, {decision})` with a decision throws `errors.unsupported.reportDecision` without network I/O (no verdict field upstream).
- Misskey detail renders the shared unfiltered list row (same cache key as filter='all'); absent when not in the loaded page, with a back-to-queue reason.
- Recategorize confirm is disabled when nothing changed (no-op PATCH refused locally); rule-ids editing rides the existing `useReportRules` hook, absent on forks without rules.
- Old tokens get the existing scopeHealth/403 upgrade prompt (verified by updated pins), never revoke.
