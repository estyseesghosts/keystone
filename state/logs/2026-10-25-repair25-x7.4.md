## Decided (→ DECISIONS)

- D9 default: strip + compress both ON at post time; per-upload
  Keep-original opt-out; videos never re-encoded (owner D9 verbatim).
- No `core/models.ts` change for the processing state: null-URL Media IS
  the state; the composer derives `processing` from it (avoids the
  conflict-table file + an ADR for an additive UI-layer derivation).
- No `Backend.checkUpload` method: the submit re-check rides the existing
  optional `updateMedia` (description write = freshness read), so no
  interface widening beyond the additive `UploadMediaOpts` fields (no ADR:
  backward-compatible options-bag addition, no wire/storage/cache-shape
  change — coordinator to confirm).
- Remind-alt pref as a single MMKV key, not a schema field: adding a 9th
  device-pref key breaks `toEqual` full-prefs literals in schema/
  storage/appearance/privacyShield suites (all outside this slice).
- `expo-file-system` used only via guarded dynamic import (W7 undeclared-
  transitive rule respected — degradation is to unknown-size, never a
  crash).
- Pick path branches on URI scheme, not `Platform.OS`: deterministic in
  every runtime (incl. web-hybrid) and test-friendly.
