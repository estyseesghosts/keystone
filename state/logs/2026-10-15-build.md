# 2026-10-15 — Frontend build (Slices 0–3)

**Goal:** build the Keystone SolidJS client per `keystone.md`; stand up a local
Pinetree server; verify end-to-end. Refs: `keystone.md`, `docs/frontend-plan.md`,
backend `pinetree/` @ `ff651d6` (pull: already up to date).

## Decisions (owner)

- Vite accepted as build/dev tooling only.
- Palette: black/white/grey, no accent colors (supersedes `keystone.md` §2
  pine-green; AGENTS.md §7 is now operative).
- Feeds: Home + Local fully; **Global route with honest fallback** — `/global`
  probes `notes/global-timeline` and shows "not supported by this server"
  instead of fake data.

## What changed (`frontend/`)

- Scaffold: `npx create-solid -p frontend -v --ts -t bare` (interactive prompts
  don't work headless; flags skip them). Solid 1.x (`solid-js ^1.9.5`), Vite 7,
  `vite-plugin-solid`. Added `@solidjs/router`, `mfm-js@0.27.0`, `-D @types/node`
  (template omission — `tsc` failed on vite's own types without it).
- `vite.config.ts`: port 5173 (template default 3000 clashes with backend) +
  `/api` + `/files` proxy → `127.0.0.1:3000`, Solid plugin intact.
- `src/api/`: `client.ts` (`apiCall`, `i`-field auth, 204-safe, `ApiError` with
  status/code), `types.ts` (wire shapes verified against packers: note/user/
  notification fields, `myReaction`, `visibleUserIds`, `isFollowing`).
- `src/state/auth.tsx`: token + me signals, startup `i` restore, auth-failure
  clears token, explicit sign-out.
- Components: `Layout` (left nav / mobile bottom bar), `NoteCard` (CW toggle,
  sensitive-media gate, counts, reaction toggle), `MfmRenderer` (allow-listed
  `mfm-js` AST per installed 0.27.0 declarations — validated `props.hashtag`,
  `props.acct`, `props.code`, etc.; unknown nodes → text; no `innerHTML`),
  `Composer` (3000 chars, public/home/followers), `TimelineFeed` (limit 20,
  `untilId` paging, refresh, failures keep loaded list), `LoadingState`,
  `ErrorState` (retry only when handler exists).
- Routes: `/login`, `/` (auth-gated), `/local`, `/global` (fallback),
  `/notifications` (shape verified vs `pack_notification`), `/notes/:id`
  (reply context as returned, reply composer, own-delete with confirm),
  `/users/:id` (follow/unfollow via `isFollowing`; no profile timeline —
  stated, not built).
- `src/styles/global.css`: monochrome only. Template leftovers removed
  (`App.module.css`, `index.css`, `logo.svg`).

- `npx tsc --noEmit` → clean. `npm run build` → green (49 modules, 87.6 kB JS).
- No React imports/hooks/`className`/`innerHTML` in `src/` (grep clean).
- Backend dev server: `CARGO_TARGET_DIR=.build/pinetree-target` (tracked
  `.cargo/config.toml` points at `/root`, read-only here — env override, repo
  untouched). Accounts alice + bob created before first start, same data-dir.
- API round-trip vs live server, 24/24 green: signin ×2, `i` restore, bad-token
  401, create ×2, local (2 notes), home auth, **global 404
  `UNKNOWN_API_ENDPOINT`**, follow, home-includes-followed, react 204,
  authed `myReaction: ❤️`, unreact 204, reply, renote, users/show,
  users/search, notifications (follow/reaction/renote/reply), delete-own 204,
  unfollow, unknown-endpoint 404, unsupported-field 400, missing-note error.

  passes with `i`); (2) first notifications read raced the server's async
  notify worker (present on re-read: follow/reaction/renote/reply).
- Vite dev serves http://localhost:5173 (200, title Keystone); `/api/meta`
  proxies to the backend.
