Decided (key shape — no ADR: shape follows the slice prescription exactly):

- Translators: **instance-owned maps**, no key string. The instance itself is the session scope (each translator is built from its session's `call`).
- Quotes: **per-backend `QuoteCache`-equivalent object** (`QuoteResolver` closure, one per `createMisskeyBackend` invocation; backends are memoized per session via `useBackendForSessionId`). No `${origin}${accountId}` key string anywhere.
- Remote-post: **shared process-wide, documented public-only** + short TTL on negatives. No per-session keying because the fetch carries no credential.
- Deleted (not deprecated) the module-level `registerSeenNote` / outcome-bus exports: keeping them as no-ops or legacy shims would preserve either a dead store or the leak. PostCard was the only importer.
- Did NOT key `requestTranslation` cache by `targetLang` (pre-existing wart, same-session only now) — out of scope, noted.
