## What changed

- `frontend/src/styles/global.css`: card outline and textfield box
  removed (text directly on the surface; toolbar hairlines bound the
  block); floating `.vispick-menu` (absolute overlay, never in-flow);
  audience pill button; monochrome Local switch; modal + drafts styles.
- `frontend/src/components/VisibilityPicker.tsx` (new): custom popup
  replacing the native select — icon/label/description rows, radio
  indicator, `menu`/`menuitemradio` semantics, outside-click/Escape.
- `frontend/src/components/Composer.tsx`: picker + switch wired in;
  `initial` (draft restore, read once) + `captureRef` (live payload
  handle) props; posting logic untouched.
- `frontend/src/api/drafts.ts` (new): per-backend localStorage store,
  cap 20 newest-first, keepable = prose or warning.
- `frontend/src/state/postbox.tsx` (new) + `App.tsx`: modal open state.
- `frontend/src/components/FloatingComposer.tsx` (new) + `Layout.tsx`:
  rail Post button (desktop + mobile, signed-in only), modal with close
  + Drafts, auto-save on dismiss, stash-before-restore, post → detail.
- `frontend/src/components/icons.tsx`: `LockIcon`, `AtIcon`,
  `PencilIcon`.
