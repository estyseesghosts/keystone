## Decided (family gaps + order)

- **History order**: server = oldest-first (`StatusEdit.ordered`), UI =
  newest-first. `adaptStatusHistory` reverses once at the adapter; no
  second ordering rule in the screen.
- **Family gaps**: Misskey family has NO history endpoint (upstream has no
  `notes/edit` at all; Sharkey edits in place and packs only `updatedAt`).
  `editHistory` is therefore absent there and the badge is non-interactive.
  Mastodon `focus` has no Misskey equivalent, so the Misskey backend drops
  it and the UI never offers a focus control.
- **Gating shape**: optional-method presence (`editHistory?`,
  `updateMedia?`) rather than a new `Capabilities` key — the same
  precedent as `dismissNotification?`, `tags?`, `domainBlocks?`. The
  composer turns presence into `ComposeGates.mediaDescription` so the UI
  reason is decided in `packages/fedi`, not inline.
- **Redraft order**: delete → (cache cleanup) → seed → open composer.
  Anything else risks a composer over a post that still exists.
- **Redraft payload**: text/CW/visibility/localOnly/media(+alt)/reply/quote
  carried; poll dropped (votes are gone — reopening one would fake a fresh
  poll); per-note `noQuote` not carried (no model field).
- **Alt-text save point**: descriptions are written BEFORE the post so a
  post never goes out with alt text the user believes they changed. A
  media-edit failure aborts the submit with the server's message.
