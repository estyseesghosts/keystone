# 2026-10-20 — P2.1 core data-layer port — subagent

Branch: `main` (orchestrator owns commits; nothing committed)
Goal: port old Keystone `core/` (9 files) + `api/error.ts` into `packages/fedi/src/core/` with RN-safe seams, convert the 5 core test files to Jest.

## Did

- Created `docs/tasks/p2.1-core.md` (status: done).
- `packages/fedi/src/core/` now holds 10 modules:
  - Verbatim copies (no i18n/DOM/window use, behaviour identical): `models.ts`, `detect.ts`, `quoteUri.ts`.
  - `backend.ts`: dropped `../i18n/locale` import. Kept English `REACTION_ACCEPTANCE_LABELS` + `NOTIFICATION_FILTER_PRESETS[].label` as fallback data; label-key codes kept with the same values but typed `string` (`REACTION_ACCEPTANCE_LABEL_KEYS`, preset `labelKey`); `reactionAcceptanceLabel(value)` returns the English label or the raw value, locale param removed.
  - `http.ts`: new `HttpError extends FediError` with `code` + `params` on every throw site (codes reuse the old message-key strings, e.g. `errors.network.crossOrigin`); messages are the fixed English wordings from the old catalog; `normalizeOrigin` throws `FediError` (still an `Error`, `toThrow` semantics kept); `locale` option/params removed from `HttpJsonOptions`/`requestJson`/`httpMessage`.
  - `core/errors.ts` (new): `ErrorCode {code, params?}`, `FediError extends Error`, `ApiError extends FediError` (ported from old `api/error.ts`: same `(message, status, code?, kind?)` signature plus optional 5th `params`).
  - `config.ts`: deleted `safeLocationOrigin()` (`location` access); `resolveHomeServer` uses only the explicit `origin` opt (first-party without one → null).
  - `hosting.ts`: `appBase({builtBase})` replaces the `import.meta.env.BASE_URL` read; `resolveHosting` already took `origin` explicitly — unchanged.
  - `boot.ts`: rewritten as `bootHosting({basePath?, origin, devFlavorHint?})` — no `import.meta`, no `location`, no `../api/backend` (`BACKEND_HINT`) import.
  - `sessions.ts`: every function takes `KeyValueStore` as first param (sync interface matching old call sites); `createMemoryStore()` helper; migration origin is an explicit param (default `DEFAULT_INTERNAL_ORIGIN = "http://localhost"`, the old non-DOM fallback); `revokeSessionToken` takes optional `store` in `RevokeOptions` for the OAuth app lookup (absent → Mastodon revoke skipped, same as old no-cache path). Session shape unchanged (`{id, origin, family, flavor, accountId, token, grant, hosting}` + optional `user`).
- Barrel `packages/fedi/src/index.ts` re-exports all 10 core modules (`export *`; no name clashes).
- Tests in `packages/fedi/test/`: `models`/`config` (dropped vitest import only), `detect` (3 fixture bodies inlined verbatim: misskey meta, mastodon instance-v2, akkoma instance-v1; `fixture()` shim kept so bodies are byte-identical), `http` (`vi.stubGlobal` → `globalThis.fetch` swap + restore; `vi.fn` → `jest.fn`), `sessions` (fresh `createMemoryStore()` per test; explicit `ORIGIN = "https://app.example"`; `localStorage`/`location` gone).
- Toolchain fixes (deviations, see below): TS parser + jest globals for the `packages/fedi` eslint block; added `packages/fedi` to `tsconfig.check.json` include.

## Decided

- Sync `KeyValueStore` (not async): matches old call sites 1:1, MMKV (slice 2.5 backing) is sync; the async SecureStore token layer wraps above. Documented in `sessions.ts` header.
- `HttpError`/`ApiError` both extend the new `FediError` so `err.code` works uniformly and `instanceof` checks survive.
- Old `HttpJsonOptions.locale` removed rather than ignored — later slices (2.2/2.3 clients) adapt at port time.
