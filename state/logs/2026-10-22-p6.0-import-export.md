## Did

- `packages/fedi/src/misskey/importExport.ts` rewritten around the upstream
  wire contract:
  - Import: `assertImportFileSize(file)` → `transport.upload(file)`
    (multipart `drive/files/create`, the existing `MisskeyClient` seam) →
    `transport.call("i/import-*", { fileId })`. `{file: text}` is gone.
    Progress phases `uploading → submitting → done`; result carries
    `endpoint`, `fileId`, and a kind-specific English fallback message
    (imports have no completion notification upstream, so the message says
    to check the list, not "wait for a notification").
  - `IMPORT_ENDPOINTS` map fixes `mute` → `i/import-muting` (upstream has no
    `import-mute`) and keeps `notes` for forks (stock Misskey 404s; the
    transport surfaces that honestly).
  - Export: `exportData(call, kind)` returns a discriminated result:
    `{status:"queued", endpoint, delivery:"notification",
    notificationType:"exportCompleted", rateLimit, message}` for the normal
    204, or `{status:"payload", payload}` when a fork answers with a body.
    One POST, no polling, no fabricated payload. Upstream rate windows are
    exported as `EXPORT_RATE_LIMITS` (notes/clips/favorites 1/day, user-lists
    1/min, the rest 1/hour). A 429 propagates as an `ApiError`.
  - `serializeExport` kept, documented as payload-only.

## Decided (no DECISIONS.md edit — this program forbids it)

- The import API takes an `ImportTransport` (`call` + `upload`) rather than
  a bare `WireCall`, so the multipart seam is injected and testable without
  DOM/`fetch` assumptions. `MisskeyClient`/`MisskeyTransport` satisfy it
  structurally.
- Export is a result union, not `unknown`: queued vs payload cannot be
  conflated, so a future UI cannot render `{}` as a notes export.
- No `Backend.transfer` member this slice. `core/backend.ts` has no
  Transfer/ImportExport types today (audit prompt assumed they existed);
  adding the surface would also need a Mastodon implementation and the
  picker UI, which is clickstone Wave 2. Module-level functions are the
  seam the UI slice will call.
- Server owns file-type validation: pickers report
  `application/octet-stream` for valid CSVs, so an extension guard would
  reject valid files. Size guard stays client-side (10 MB).
