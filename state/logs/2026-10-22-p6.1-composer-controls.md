Family decisions (verified against the read-only sources, not guessed):

- Misskey family `notes/create` accepts `noQuote`; `notes/edit` forwards
  the caller's value (`packages/fedi/src/misskey/{backend,noteEdit}.ts`).
  Create omits false; edit omits false too — `Post` carries no `noQuote`,
  so sending `false` on every edit would silently lift a refusal the
  composer never showed. `true` is sent when toggled on.
- `drive/files/create` takes `isSensitive` per file (Sharkey
  `packages/backend/src/server/api/endpoints/drive/files/create.ts:83`) —
  the attach-time toggle rides on the upload call.
- Mastodon family: `/api/v1/statuses` takes status-level `sensitive` and
  `quote_approval_policy` (4.5, `post_status_service.rb:38`), but the
  media endpoints accept only `file`/`thumbnail`/`description`/`focus`
  (`app/controllers/api/v1/media_controller.rb:52`) — no per-media field.
  Neither `noQuote` (unknown field) nor a per-media `sensitive` is sent.
  Per-post quote refusal on Mastodon 4.5 is a real server feature but is
  NOT in our wire/contract, so the control is disabled with a client-gap
  reason ("Keystone cannot set quote refusal per post on this server
  yet.") rather than claiming the server lacks it.
- Verification debt worth naming: the read-only Sharkey clone here
  (2025.5.2-dev) does not show `noQuote` in `notes/create`'s paramDef,
  while v1 (`Composer.tsx:277,369`) sent it and clickstone §1.2/audit A2
  treat it as live. This slice follows v1 + the existing wire (the field
  was already sent before this change); a rig check on Misskey `:3101` /
  Sharkey `:3102` (both currently refusing) should confirm the toggle
  changes `noQuote` on a real note.

Decided (→ coordinator for `docs/DECISIONS.md`; NOT written here):

- Per-note refusal is a separate capability from `quote_posting`: quote
  posting may be supported while a per-note refusal field is not, and the
  gate must be honest about which is missing.
- Attach-time sensitivity is `media_sensitivity`, not `drive`: Drive
  support and per-file sensitivity are different server facts (Pinetree
  has no drive but the family shape is Misskey).
- Edit never sends `noQuote: false` until the domain `Post` carries the
  flag to seed the toggle (otherwise an edit silently unrefuses quotes).
- Mastodon 4.5 `quote_approval_policy: "nobody"` is the natural follow-up
  (per-note, unlike the account-wide `rejectQuotes`), but it is Akkoma/
  Pleroma-unsafe and outside this slice.
