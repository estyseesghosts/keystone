Behaviour: shadow flips sync; rapid changes coalesce (like->unlike in flight = react, unreact; like/unlike/like = react only); reject rolls back to confirmed value and rejects the promise (callers `.catch` -> toast); reaction change = `unreact` then `react` (delete landed + create failed => confirmed null via `PartialToggleError`). On idle the confirmed value is written into every cached copy for THAT session (feed pages, single post, notification rows, nested renote/quote/reply) and the shadow field is dropped. A shadow override is ignored once the post's own server value differs from the value it was based on (fresh server data wins). If no cache carries the post, the override is kept (base guard drops it later). Delete success keeps `isDeleted` and removes the post from the session's caches.
