# 2026-10-16 — Branched replies (`docs/replies.md` Slices A–C)

## Goal

Render discussions as a real reply tree on `/notes/:id`, matching the
reference client (`docs/openpost.png`): open any post → ancestor context
above, the post, the reply composer, then **every** direct reply below —
and every reply clickable into its own detail view with its own thread.

## What changed

- `frontend/src/api/thread.ts` (new): `REPLIES_PAGE_SIZE` (20),
  `CONVERSATION_PAGE_SIZE` (30), `MAX_ANCESTOR_WALK` (512),
  `THREAD_MAX_DEPTH` (32); pure `mergeNotes` (order-preserving id
  dedupe, loaded identities kept) and `orderAncestors` (replyId-chain
  walk from the displayed note, oldest-first, extras ignored,
  cycle-safe, bounded).
- `frontend/src/components/ReplyList.tsx` (new): `ReplyList` (direct
  children of one parent via `notes/replies`, per-instance
  loading/error/retry/cursor/dedupe/exhaustion, `untilId` paging to
  exhaustion, always queries `appearNoteOf` ids, 404 → honest
  "not available" state) + `ReplyBranch` (read-only card, always-shown
  Show/Hide replies toggle with count, lazy nested mount, cycle guard,
  explicit too-deep state).
- `frontend/src/routes/Note.tsx`: ancestor `Thread` section via
  `notes/conversation` (limit/offset paging with no-growth + 512
  guards), neutral "Earlier reply context unavailable" marker (never an
  id/URI), 404 fallback to the packed one-level parent, region-local
  retry that never touches the selected note; root `ReplyList` with
  `injected` prepend on post (no refetch, branches undisturbed);
  route-param-driven reload with a generation guard (stale responses
  discarded); Refresh reloads note + context + branches; poll votes
  reconcile quietly (`refreshPage`) without collapsing branches;
  branch cards link every reply into its own detail view.
- `frontend/src/styles/global.css`: reply-tree styles — monochrome
  toggle row aligned under note text, nested indent + connector with
  the indent capped past four levels (depth unlimited), tighter indent
  under 720px, global visible-focus rule reused.
- Docs: `docs/replies.md` status → implemented; `docs/frontend-plan.md`
  Slice 2 + new Branched-replies section; `state/STATE.md` pointer.
