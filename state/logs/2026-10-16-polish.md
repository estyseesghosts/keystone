# 2026-10-16 — Visual polish (sidebar icons, collapse, dark mode, composer)

Goal (owner request): vector icons per sidebar item, collapsible
icon-only sidebar, system-theme dark mode, unified composer card, nicer
buttons/options. One scoping round first: dark mode contradicted the
AGENTS.md §7 light-only guard, so asked — owner chose "Yes, override the
guard" and "persist collapse, default expanded". AGENTS.md §7 updated to
record the override (light default; dark follows `prefers-color-scheme`;
no toggle, no further theme infrastructure).

## What changed (one commit, visual-only)

- `frontend/src/components/icons.tsx`: 10 new monochrome stroke icons in
  the existing style (Home, Local/users, Global/globe, Search, Drive/
  folder, Antennas/radio-tower, Bell, Login, Logout, Collapse chevrons)
  on a shared `Base` (currentColor, default 18px).
- `frontend/src/components/Layout.tsx`: every nav item gets icon + label
  (`title`/`aria-label` kept so the collapsed rail stays accessible);
  desktop collapse toggle (persists `keystone_nav_collapsed`, session-only
  fallback); brand collapses to "K".
- `frontend/src/styles/global.css`: collapsed rail (68px, centered icons,
  labels/user text hidden); mobile bottom bar stacks icon over 10px label
  and hides the toggle; dark palette via one variable swap +
  `color-scheme: dark`; composer becomes a flat bordered 12px-radius card
  (no shadows per guard); unified 8px radii + soft hover states on
  buttons/nav/inputs (primary keeps inverted fill, dims on hover).
