## Follow-up (coordinator-verified failure, same day)

- Failing test: `packages/fedi/test/sessions.test.ts` › `utf8Hex` › `lone surrogates encode as U+FFFD` — `utf8Hex("\ud800")` returned `"eda080"` (CESU-8 of the raw surrogate) instead of `"efbfbd"`.

- Fix (this file only, 2 lines): enter the high-surrogate branch unconditionally; read `next` as `-1` at end-of-string so the low-surrogate check fails and the `else` encodes U+FFFD. Valid pairs, lone lows, ASCII, and multi-byte paths are byte-identical to before. No other file touched (coordinator owns the moved vault interfaces / union typing around this slice).
