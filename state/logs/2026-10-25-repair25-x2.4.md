## Decided

- Rebasing DNS names that resolve to private IPs (DNS rebinding, split-horizon intranet DNS) cannot be detected without resolver support the device does not expose: documented out of scope in `urlPolicy.ts`.
- Remote-post page URL (`object.url`) is NOT policy-gated on return: it is only ever opened/copied by explicit user action (browser navigation is user-initiated). Only the silent fetch is gated.
- Link-preview proxy URL itself is operator-configured and trusted as-is; every redirect hop after it is re-checked.
- Trailing-dot FQDNs (`example.com.`) are rejected outright rather than normalized.
- No Bluesky source consulted (no Bluesky pattern involved); nothing recorded in code comments per AGENTS.md §5.
