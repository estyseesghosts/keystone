## Decided

- Region semantics live on the Modal **content root**, never the card/sheet alone: a card-level `role="dialog"`
  hides its sibling backdrop (the dismiss control) from AT and from RNTL queries — found by bisect when the
  pre-existing Dialog backdrop test failed; root placement is also semantically correct (scrim + sheet = dialog).
- `role="alert"` asserted via props, not `getByRole`, inside the toast tree (nested-in-accessible hiding).
- Matrix anchor testID added (`richtext-matrix-hover-anchor`): RN Pressable wires its own hover/focus props on
  inner hosts, so an ancestor-walk for handlers is unreliable.
- Keyboard-suite ordering: my HoverPreview DOM tests run AFTER `layout-shift ghosts` (comment in file) — the
  pointer tracker attaches once per process; focus opens bypass the gate either way.
- 4 new `msg` ids (chip labels) left unextracted for the coordinator (`src/locale/*` untouched, no extract run).
