# 2026-10-15 — Quotes: backend support + clickable embeds

**Goal:** answer "are quotes wired in the backend?" and make them clickable.

## Backend findings (read-only inspection + live probe)

- No `quote` concept anywhere in `src/` (no endpoints, no domain type, no
  metadata). Consistent with `keystone.md` §7 ("quote metadata" out of scope).
- But Misskey-style quotes work through the generic path: `notes/create`
  accepts `text` + `renoteId` together (`domain/note.rs` validation only
  requires non-blank text when there is *no* renote/files), and `pack_note`
  embeds `renote` one level. Live probe: create with text + renoteId → 200,
  `renoteId` set, embedded `renote` present; deleted after (204).
- So: quote *creation and display* are supported; quote *endpoints/metadata/
  listings* don't exist (same class of gap as renotes/replies lists).

## Frontend changes

- `NoteCard`: renders `note.renote` as a bordered embed (name, handle, MFM
  text) wrapped in `<A href=/notes/:id>` — pure renotes are no longer blank,
  unclickable cards. Shown inside the CW gate with the rest of the body.
- `Composer`: new `renoteId` prop (params, placeholder, button label).
- `routes/Note.tsx`: "Quote this note" toggle + quote composer; on post,
  hides composer and reloads detail.
- `docs/api-surface.md`: create row now records quote = text + renoteId.

## Evidence

- `npx tsc --noEmit` → clean.
- Live quote round-trip: 200 with embedded renote; cleanup delete 204.
