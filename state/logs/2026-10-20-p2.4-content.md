## Decided (→ DECISIONS.md transcription by orchestrator)

- `htmlparser2@12.0.0` added (root + `packages/fedi/package.json` dep entry mirroring the `mfm-js` pattern); pure JS, no WASM/node-only code — Hermes-safe. ESM-only, so root `package.json` jest `transformIgnorePatterns` extended with `htmlparser2|domhandler|domutils|dom-serializer|entities|domelementtype` (else jest CJS cannot load it; Metro/RN unaffected).
- `babel-preset-expo` `lazyImports` defers the ESM require into the first `parseDocument` call — with no transform this silently degrades `contentFromHtml` to `[]` inside its try/catch (diagnosed via probe test; the transform fix resolves it, tests prove loading).
- Link-preview swap: `DOMParser` → `htmlparser2`, streaming `ReadableStream` byte-cap → `text()` + slice (RN fetch bodies are not guaranteed streams); `fetchImpl` + `proxy` seams; card shape and proxy opt-in unchanged.
- `groupCustomByCategory` locale seam → plain-string label (data layer holds no locales).
- AST block encoding: no paragraph/list nodes — blocks join with `br` pairs (both parsers agree); unknown tags degrade to children.
- Akkoma `pleroma.content['text/plain']` → `content.mfm` (+ MFM-derived `plain`); vanilla Mastodon stays HTML-only. Bios untouched (posts only).
- Old `api/client.ts`+`api/backend.ts` facade deferred to 2.5/2.6 (needs the session store; no half-port).
